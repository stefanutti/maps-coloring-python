# Maps Coloring Python

Python implementation of an experimental Four Color Theorem algorithm based
on Tait edge-coloring, graph reduction, and Kempe-chain color switching.

The homepage with the full story is
[4coloring.wordpress.com](https://4coloring.wordpress.com).
